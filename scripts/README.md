# Monorepo Scripts & Utilities

## 1. Overview
This directory contains automation, developer tooling, database maintenance, and validation scripts for the Cloud Management Platform (CMP).

## 2. Planned Scripts
- `dev-check.sh`: Verifies local development prerequisites (Python, Node, Go, PHP, PostgreSQL connectivity).
- `setup-dev.sh`: Bootstraps local environments and sets up configuration files.
- `seed-db.sh`: Seeds mock data into the Django core backend for local testing.
